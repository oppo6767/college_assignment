# 대학교 과제 - 사이트 제작

## 소개
사진 업로드 사이트

## 기능
홈 화면 애니메이션
갤러리 보기
이미지 삭제
드래그 & 드랍
이미지 업로드 및 미리보기 화면

## 파일 구조
index.html - 홈 화면
home.css - 홈 화면 설정
scroll.js - 홈 화면 기능
-------------------
gallery.html - 갤러리 화면
gallery.css - 갤러리 설정
gallery.js - 갤러리 기능
-----------------
drop-zone.html - 드래그 & 드랍 화면
drop-zone.css - 드래그 & 드랍 설정
drop-zone.js - 드래그 & 드랍 기능
-----------------------
upload.html - 미리보기 및 업로드 화면
upload.css - 미리보기 및 업로드 설정
upload.js - 미리보기 및 업로드 기능

## 사용 기술
HTML
CSS
JavaScript

## 주의사항
웹 브라우저 메모리(localStorage-base64) 기반으로 이미지 저장 한계 있음
작은 이미지 기준 약 12~38장 저장 가능
